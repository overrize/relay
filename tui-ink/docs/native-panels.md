# 原生 TUI：固定输入、键位与运行面板

运行 `E:\spawn-work\relay.cmd --ui=native`。采用与 OmO 同类的 `TuiAltScreen + ScrollView + VStack`：上方可滚动，下方固定状态、提示、编辑器和底栏。没有同时启用旧 UI 的 raw-input 或光标补丁。

## 操作

| 入口 | 用途 |
| --- | --- |
| PageUp / PageDown、滚轮 | 滚动上方历史或面板；输入焦点保留。翻看旧消息时不被后台输出拉回。 |
| Alt+End | 回到当前内容末尾，聊天恢复跟随新输出。 |
| `/older`、Alt+N | 从持久日志/保留归档读取更早 PM 消息，默认每页 80 条，按稳定序号继续；不是只有最近 50 条恢复投影。 |
| `/tasks`、Ctrl+B | Agent 状态、任务目标/版本、停止原因、重试与请求/工具预算、验收、操作状态。 |
| `/budget` | 工作区累计预算、剩余请求/工具/Token、未结算预留、未定价费用、API/订阅分别统计、停止原因。 |
| `/audit [model=ID task=ID before=序号 limit=1..200]` | 后台校验长期审计，展示模型/任务累计、明细与关联 ID。筛选只影响明细；Alt+N 读取更早明细，F5 刷新当前页。 |
| Alt+↑ / Alt+↓ | 切换任务或审计的选中条目，查看详情。 |
| Esc、`/chat` | 关闭面板并返回聊天；关闭面板不取消执行。聊天中 Esc 才中断当前任务。 |
| `/keys` | 重新读取 `keybindings.json` 并显示当前映射；配置冲突时保留最后有效配置。 |
| Ctrl+C | 有草稿时清空；空输入时停止本进程并退出，保留恢复账本。 |

面板打开时仍能输入、发送 PM 追问和 `/revise 新目标`。登录等弹层临时占用编辑区，取消恢复同一个 Editor、草稿和光标。后台读取失败会显示错误，不返回半份审计统计。

## 自定义快捷键

文件位置与配置相同：`SPAWN_CONFIG_DIR/keybindings.json`。没有指定配置目录时使用原有默认目录。启动读取，修改后 `/keys` 重载，例如：

```json
{
  "app.history.search": "f2",
  "app.viewport.up": "f3",
  "tui.input.submit": "ctrl+s",
  "tui.select.down": "ctrl+j"
}
```

沿用旧 UI 的动作 ID、作用域、禁用默认键和冲突检测。禁用默认键后不会意外触发其原动作；完整粘贴块直接交给原生编辑器，不将块中的控制字解释为快捷键。物理键优先于工具库的 Alt+N/P 导航别名，CSI-u 键仍由工具库解析。编辑器导航、撤销、换行、模型轮换、模型用途/收藏/保存默认和选择器动作均通过统一入口适配，提示随键位变化。

推理调节仍取决于当前接入能力；本界面未提供独立推理视图。原生编辑器没有重做 API，重做动作明确提示不可用，避免被误作粘贴。尚未切换默认界面，也没有移除旧入口。
