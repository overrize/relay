# 重复打开 Relay 与工作区占用

同一工作区当前只允许一个执行实例。正式入口在加载 TUI、HTTP 服务、会话日志和自动维护前取得工作区所有权。

再次启动时，如果已有存活进程占用，新进程直接显示中文提示与占用 PID，返回已有 Relay 窗口使用，或先在原窗口正常退出后再启动。当前尚未实现自动聚焦原窗口或附着同一后台会话，因此不会展示一个随后无法提交的第二个 TUI。

所有权检查不会终止已有进程，也不会删除存活进程的锁。原进程正常退出会释放所有权；进程被强杀后，在确认记录 PID 已不存在且记录未被替换时可重新取得所有权。转移锁处于中断/未知状态时保留现场，明确提示检查。

输入提交另设错误边界。被拒的提交保留编辑内容，不加入已提交历史，不将 PM 标为已启动；用户可以编辑后重试。根 PM 启动的所有权检查也提前到创建提示和打开会话日志之前。
